# Support

Start with the [documentation](docs/README.md) and `teardown --help`. For a
question or reproducible bug, open a
[GitHub issue](https://github.com/ReyemTech/teardown/issues) with the package
version, Python version, command and relevant redacted output. For usage
questions, explain the result you expected and the result you received.

Keep secrets, private domain details, source-map contents, and personal data
out of public issues. For a vulnerability in Teardown, use
[private reporting](SECURITY.md). For a finding about a scanned site, contact
that site's operator through its disclosure channel.
